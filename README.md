# FastPizza Ordering System

A modern React application demonstrating React Router v6.4+ Data APIs (loaders & actions), render-as-you-fetch strategy, and feature-based architecture.

## Key Concepts Implemented

- Route-based data loading using loaders
- Form submission using route actions
- Render-as-you-fetch pattern
- Route-level error boundaries
- Centralized API service layer
- Feature-first folder structure
- Global loading state via useNavigation

## Tech Stack

- React
- React Router v6.4+
- JavaScript (ES6+)
- CSS
